# Тридевятые земли

Пошаговая стратегия в духе Heroes of Might and Magic 2 по мотивам русских сказок.

**Играть:** https://volik1987.github.io/tridevyatye-zemli/

- Три царства: Тридесятое (богатыри), Лесное (Леший, Кот Баюн), Кощеево (нежить, Змей Горыныч)
- Карта создаётся заново каждую партию, города, рудники, диковины, чудища
- Тактические бои на гексах, чары героя, прокачка уровней
- Работает в любом браузере на компьютере и телефоне, весь код в одном файле `index.html`

Сохранение — автоматически в конце каждого дня (в браузере игрока).
